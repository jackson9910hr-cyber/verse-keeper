# Verse Keeper 개인정보처리방침 / Privacy Policy

> 시행일 / Effective date: 2026-XX-XX · 문의 / Contact: `support@example.com` (자리표시 — 출시 전 실제 주소로 교체)

## 한국어

**Verse Keeper(이하 "앱")는 어떤 개인정보도 수집·저장·전송하지 않습니다.**

1. **수집하는 정보 없음** — 앱에는 계정, 로그인, 서버, 광고, 분석 도구, 크래시 리포팅 도구, 추적 기능이 없습니다. 앱은 인터넷에 연결하지 않습니다.
2. **기기 안에만 저장되는 정보** — 사용자가 입력한 가족 구성원 이름, 구절 본문, 태그, 학습 기록과 설정은 기기 안의 데이터베이스에만 저장됩니다. 개발자를 포함한 누구에게도 전송되지 않습니다. 앱을 삭제하면 이 데이터도 함께 삭제됩니다.
3. **알림** — 사용자가 "매일 복습 알림"을 켜면 iOS 알림 권한을 요청하고, 알림은 기기 안에서만 예약됩니다. 원격(푸시) 알림 서버는 사용하지 않으며, 알림 내용에는 개인 데이터가 들어가지 않습니다.
4. **백업 파일** — "백업 내보내기"를 누르면 모든 앱 데이터가 들어 있는 JSON 파일이 만들어지고 iOS 공유 시트가 열립니다. 파일을 어디에 저장하거나 보낼지는 사용자가 정하며, 개발자는 이 파일을 받지 않습니다. 백업 파일에는 가족 구성원 이름이 들어 있으므로 안전한 곳에 보관하세요.
5. **데이터 삭제** — 설정 > 모든 데이터 삭제에서 언제든 전체 데이터를 지울 수 있습니다.
6. **어린이** — 앱은 어린이를 포함한 누구의 개인정보도 수집하지 않습니다.
7. **변경** — 이 방침이 바뀌면 이 페이지에 게시하고 시행일을 갱신합니다.

## English

**Verse Keeper ("the app") does not collect, store on any server, or transmit any personal information.**

1. **No data collection** — The app has no accounts, login, servers, ads, analytics, crash reporting or tracking. It does not connect to the internet.
2. **On-device data only** — Family member names, verse text, tags, study history and settings you enter are stored only in a database on your device. They are never sent to the developer or anyone else. Deleting the app deletes this data.
3. **Notifications** — If you turn on the daily review reminder, the app asks for notification permission and schedules reminders locally on the device. No push server is used and reminders contain no personal data.
4. **Backup files** — "Export backup" creates a JSON file containing all app data and opens the iOS share sheet. You choose where the file goes; the developer never receives it. Backups contain family member names, so keep them somewhere safe.
5. **Deleting data** — Settings > Delete all data erases everything at any time.
6. **Children** — The app collects no personal information from anyone, including children.
7. **Changes** — Any change to this policy will be posted on this page with a new effective date.
