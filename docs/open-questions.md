# Verse Keeper — 결정 필요 사항 (open-questions.md)

> Stage 0 산출물 · 각 질문에 **권장안**을 적어 두었다. 문서는 권장안을 기준으로 작성했으므로, 답이 다르면 해당 문서만 고치면 된다.
> **2026-09-25 진행 결정**: 사용자가 "배포까지 완료"를 지시해 Q1~Q3, Q7~Q18은 권장안으로 확정해 구현했다. Q4(앱 이름)·Q5(Bundle ID)는 자리표시 기본값(`Verse Keeper`, `io.github.jackson9910hr-cyber.versekeeper`)으로 두고 `app.config.ts`에서 바꿀 수 있다. Q6(Apple Developer 계정)은 사용자가 해야 하는 일이다.
>
> 답변 형식 예: `Q1: A, Q2: B, Q3: 권장, Q4: "말씀지킴이", Q5: com.example.versekeeper, Q6: 있음 …`

## A. 필수 질문 (Stage 1 전에 필요)

| # | 질문 | 선택지 | 권장안 · 근거 | 영향 받는 문서 |
|---|---|---|---|---|
| **Q1** | KJV를 기본 팩에 포함할까? | A. 포함 안 함 / B. 포함(영국 제외 배포) / C. 포함(전 세계) | **A** — 영국 Crown 특허 이슈. WEB만으로 영어 암송에 충분하고 현대 영어라 암송하기에도 낫다. 사용자가 KJV를 직접 입력하는 것은 가능 | spec §4, risks R15 |
| **Q2** | 한국어 "첫 글자 힌트" 규칙 | A. 첫 음절 + ○ (`태○○`) / B. 초성 (`ㅌㅊㅇ`) / C. 둘 다 지원, 기본값 선택 | **C, 기본 A** — A는 영어의 "첫 글자"와 체감 난이도가 비슷하고, B(초성 암송법)는 한 단계 어려운 모드로 쓸 수 있다. 구현 비용 차이는 작다 | algorithms §4, data-model 설정 키 |
| **Q3** | 가족 구성원 프로필(이름만)을 둘까? | A. 둔다(프로필별 진도·streak) / B. 두지 않음(가족 구절만 공유) | **A** — 한 기기를 가족이 함께 쓰면 진도가 섞이는 것이 가장 큰 불편이다. 지금 스키마에 넣지 않으면 나중에 마이그레이션 비용이 크다. 최대 8명, 이름과 색상만 | spec US-ON-2, data-model 전체 |
| **Q4** | 앱 이름 | "Verse Keeper"와 비슷한 **"Bible Verse Keeper"가 App Store에 이미 있다** | **이름 후보 중 선택 권장**: ① `Verse Keeper: 성경 암송` (부제로 구분) ② `말씀 지킴이 – Verse Keeper` ③ `Hide the Word` (시 119:11) ④ 직접 제안. App Store Connect에서 이름 예약으로 최종 확인 | risks R3, Stage 4 메타데이터 |
| **Q5** | Bundle ID | 예: `com.<회사 또는 이름>.versekeeper` | 한 번 등록하면 **변경할 수 없다**. 개인 도메인이 없으면 `io.github.<GitHub ID>.versekeeper` 형식 권장. 회사(두산에너빌리티) 이름은 개인 앱에 쓰지 않을 것을 권장 | Stage 4 app.config |
| **Q6** | Apple Developer Program 계정이 있는가? | 개인 / 조직 / 없음 | 개인 계정(연 US$99)으로 시작 권장. 조직 계정은 D-U-N-S 번호가 필요하고 몇 주 걸린다. 스토어의 판매자 이름이 개인 실명으로 표시된다는 점 참고 | Stage 4 release.md |

## B. 추가 확인 질문 (권장안으로 진행해도 됨)

| # | 질문 | 권장안 |
|---|---|---|
| Q7 | 카드 단위: 한국어·영어를 별도 카드로 복습할까? | **예** (기억 강도가 언어마다 다름). 구절 상세에서 언어별로 "학습 시작" |
| Q8 | 빈칸 레벨 5단계(20/40/60/80/100%) | **예**. 레벨은 카드별로 저장하고, "좋음/쉬움"으로 3회 연속 통과하면 다음 레벨을 제안(자동 상승 아님) |
| Q9 | 새 카드 하루 제한 | v1은 제한 없음(가족 구절과 사용자가 고른 구절만 들어오므로 폭증 위험 낮음). 세션 크기로만 제한 |
| Q10 | streak 기준 | 평가 1회 이상이면 그날은 학습한 날. 복습할 카드가 없는 날도 "연습"으로 streak 유지 가능 |
| Q11 | 알림 기본 시간 | 20:00 (가족 저녁 시간) |
| Q12 | 지원 언어 | UI 한국어/영어. 기본 팩 태그와 책 이름도 두 언어 모두 제공 |
| Q13 | iPad 지원 | 지원(`supportsTablet: true`), iPhone 레이아웃 + 최대 폭 제한. iPad 스크린샷이 추가로 필요하다는 점 참고 |
| Q14 | 최소 iOS 버전 | Expo SDK 57 기본값을 따름 |
| Q15 | 개인정보처리방침·지원 페이지 호스팅 | 이 저장소의 GitHub Pages(`/docs` 또는 `gh-pages`). 저장소가 private이면 Pages에 유료 플랜이 필요할 수 있으므로 별도 public 저장소 권장 |
| Q16 | 연락처 이메일 | 자리표시로 두고 Stage 4에서 입력(개인 이메일 노출을 원하지 않으면 별도 지원용 주소 권장) |

| Q18 | 커밋 규칙 | Conventional Commits + commitlint + husky 도입 |
